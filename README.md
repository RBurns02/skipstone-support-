# Skipstone — support & privacy

The support and privacy pages for the Skipstone iOS app, served by GitHub Pages
so that App Review and customers can reach them without a login.

- [Support](https://rburns02.github.io/skipstone-support-/support.html)
- [Privacy Policy](https://rburns02.github.io/skipstone-support-/privacy.html)

These are plain static pages with no build step. Edit the HTML and push; Pages
redeploys on its own.
